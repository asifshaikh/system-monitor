#  System Monitor

A Bash-based log analysis tool that processes application log files and generates a structured summary report.

---

##  Features

- Log file validation (argument, existence, permissions)
- Total line count
- ERROR and WARNING count
- Top 3 most frequent words (ranked)
- Structured summary output
- Dockerized execution support
- Proper exit codes

---

```
system-monitor/
```

##  Requirements

- Linux / Bash environment
- Git

---

##  Manual Execution (BASH)
### 1) Clone the Repository
```bash
git clone https://github.com/asifshaikh/system-monitor.git
cd system-monitor
```
### 2) Make the script executable
```bash
chmod +x monitor.sh
```
### 3) Run the script with argument
```bash
./monitor.sh logs/sample.log
```
### 4) View the generated summary
```bash
cat summary.txt
```
## Docker Execution
### 1) Build Image using Docker/Podman
```bash
docker build -t system-monitor:latest .
```
```bash
podman build -t system-monitor:latest .
```
### 2) Run Container (Bind Mount Current Directory)
```bash
docker run --rm -v $(pwd):/app system-monitor:latest logs/sample.log
```
```bash
podman run --rm -v $(pwd):/app:Z system-monitor:latest logs/sample.log
```
### 3) View the summary on host machine
```bash
cat summary.txt
```

## Summary Output Explanation
After execution, `summary.txt` is generated in the project root with the following structure:
 
```
========================================
           LOG SUMMARY REPORT
========================================
Input File        : logs/sample.log
Generated On      : YYYY-MM-DD HH:MM:SS
Generated By      : monitor.sh
----------------------------------------
BASIC STATISTICS
----------------------------------------
Total Lines       : XX
ERROR Count       : XX
WARNING Count     : XX
----------------------------------------
TOP 3 FREQUENT WORDS
----------------------------------------
1. word1 - XX
2. word2 - XX
3. word3 - XX
----------------------------------------
END OF REPORT
----------------------------------------
```
### Explanation
- Input File → Path to the log file
- Generated On → Timestamp of report generation
- Generated By → Name of the script that generated the report
- Total Lines → Total entries in log file
- ERROR Count → Number of ERROR occurrences
- WARNING Count → Number of WARNING occurrences
- Top 3 Frequent Words → Most commonly occurring words ranked by frequency

## Exit Codes
| Code | Meaning |
|---|---|
| `0` | Script executed successfully |
| `1` | Incorrect argument count |
| `2` | File does not exists |
| `3` | File not readable |
